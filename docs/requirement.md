# Maisie Paw Prints — Requirements

## 1. Customer

### 1.1 Browse Products
- Customer can view available products.
- Customer can view product details.

### 1.2 Place Order
- Customer can select a product.
- Customer can provide their name.
- Customer can provide their email.
- Customer can upload pet images.
- Customer can submit the order.

## 2. Admin

### 2.1 Authentication
- Admin can log in.
- Admin can log out.

### 2.2 Order Management
- Admin can view orders.
- Admin can view uploaded images.
- Admin can update order status.
